# 第十七阶段：第二次自蒸馏——锐化成功，覆盖面变窄

**结论先说**：pass@1 涨到 **54.2%**（历史最高），但 k=4 的解出题数从 150 掉到 **141**。
第十阶段那次自蒸馏是三个口径同时涨，这次不是。**M（150/200）仍然是 k=4 口径下最好的模型。**

不过 Q 在 k=16 上解出 **163/200**，是全项目覆盖面最高的一次读数。

## 1. 为什么做这一轮

复盘每个模型的来路时发现一件被忽略的事：

| 模型 | 怎么来的 | 解出（k=4） |
| --- | --- | ---: |
| F | 第八阶段 SFT（撤掉文档包） | 84 |
| **H** | **自蒸馏 SFT（从 F）** | **108** |
| I | GRPO（从 F） | 98 |
| J | GRPO（从 H） | 127 |
| K | GRPO（从 H，类别平衡） | 134 |
| L | GRPO（从 H，数值分级） | 144 |
| M | GRPO（从 L，纯度分级+链尾） | 150 |
| N | GRPO（从 M，纯度上限 0.3） | 147 |
| O | GRPO（从 M，速度目标） | 147 |

**自蒸馏只用过一次**（H，+24 道，全项目单项最大），此后七个模型全是 GRPO，而 GRPO 的边际
收益已衰减到负（+19 → +7 → +10 → +6 → −3 → −3）。M 比 F 强得多（150 对 84），
它自己的通过解作为训练材料应该好得多。

## 2. 数据

2300 道训练题（三个池子）各采 k=8，共 18,385 个样本，带计时验证：

| | 通过率 | 中位加速 |
| --- | ---: | ---: |
| level 86 | 75.0% | 2.260x |
| level 87 | 81.8% | 2.448x |
| level 89 | 78.3% | 2.073x |

（L 那次在 level 86 上是 65.4%，M 确实更强。）

构建出的自蒸馏集是 **4,220 条、覆盖 2,145 道任务**，接近第十阶段（1,534 条 / 826 道）的
三倍，而且类别均衡得多——**池化 609 条**，第十阶段只有 181 条。

训练 63 分钟，零 NaN 丢弃。

## 3. 结果：锐化了，也变窄了

k 对齐到 4，速度对 `torch.compile`：

| | pass@1 | pass@4 | 解出 | 快过 compile | 中位 |
| --- | ---: | ---: | ---: | ---: | ---: |
| L | 44.6% | 72.0% | 144/200 | 41 | 0.92x |
| **M** | 51.6% | **75.0%** | **150/200** | 43 | 0.92x |
| Q | **54.2%** | 70.5% | 141/200 | 43 | **0.94x** |

Q 自己的 k=16 曲线：

| | pass@1 | pass@4 | pass@16 |
| --- | ---: | ---: | ---: |
| Level 1 | 67/100 | 79/100 | **89/100** |
| Level 2 | 39/100 | 62/100 | **74/100** |
| 合计 | 106/200 | 141/200 | **163/200** |

**163/200 是全项目覆盖面最高的读数**，但要说清楚：M 只采了 k=4，这个口径下没有 M 的数字
可比，所以不能说"Q 的覆盖面超过 M"。

得失明细（k 对齐到 4）：

| | Q 保住 | Q 丢 | Q 得 |
| --- | ---: | ---: | ---: |
| Level 1 | 78 | 7 | 1 |
| Level 2 | 54 | 11 | 8 |

Level 2 丢的 11 道里 **10 道是"数值正确但没过纯度门"**——和第十五阶段那次一样的形态。

## 4. 和第十阶段的区别

第十阶段的自蒸馏是**三个口径同时涨**（pass@1 43 → 57、pass@4 79 → 108、pass@16 129 → 145），
我当时特意确认了"没有拿覆盖面换可靠性"。这次不是。

差别大概在余量：那时 F 只解出 84 道，大量题目是"偶尔能做对"，蒸馏把它们变成"稳定做对"，
覆盖面和可靠性一起涨。现在 M 已经 150 道，剩下的题大多是"很少能做对"，
**蒸馏在这些题上强化的是多数派写法，而少数派里那个偶然对的解被压掉了**——这正是
pass@1 涨、pass@4 跌的机制。

**这是连续第三轮出现同一形态**（N 的纯度上限、O 的速度、Q 的自蒸馏）：pass@1 涨、解出跌。
不是三个独立的失误，而是同一个信号——**在当前能力水平上，任何形式的锐化都在拿覆盖面换
可靠性**。想再涨 k=4 的解出数，得靠扩覆盖面的手段（新能力、新任务形态），而不是锐化。

## 5. 下一步

1. **k=4 这个口径本身值得重新审视。** 如果实际使用会采多次（工程上很自然），
   那 Q 的 163/200 比 M 的 150/200 更有意义。这是评测口径的选择，应该显式决定而不是默认。
2. **想涨 k=4 的解出数，需要扩覆盖面**：Level 2 剩的纯度失败、以及从没解出的那批题。
   锐化这条路的三次尝试都表明它在当前水平上是零和的。
3. M 和 Q 都保留：M 是 k=4 最好，Q 是 pass@1 和 k=16 最好。
